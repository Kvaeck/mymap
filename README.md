# MyMap 🧠

MyMap is a modern, lightweight, and open mind mapping tool built with Python & PyQt.  
It helps you visually organize ideas, brainstorm, and structure projects.  

## Features (Milestone 0)
- Basic PyQt app skeleton
- Opens a blank window

## Roadmap
- Milestone 1: Basic node editor
- Milestone 2: Connections & layout
- Milestone 3: Styling & usability
- Milestone 4: File & project management
- Milestone 5: Productivity features
- Milestone 6: Licensing & packaging
- Milestone 7: Collaboration & cloud
